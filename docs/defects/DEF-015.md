# DEF-015 · free/self 票据不校验订单 + 自助申报可匿名申领

- **来源缺陷编号**：SEC-02（最终报告 §7.6【阻断】）
- **严重度**：阻断
- **负责域**：安全（关屿）
- **关联修复方案引用**：报告 §7.6 ③

## 问题描述
`requirePaidAccess` 仅 `mode=paid` 校验真实订单；`free/self` 签名有效即放行；`self-report` 在「未配真实通道 + 已传二维码」下匿名 5 次/分换 30 分钟票据（机器不核对到账）。串联成免费下载链路，票据 TTL 内可无限重放。

## 复现 / 证据
- **测试 bug 点（文件:行号）**：
  - `lib/pay-access.ts:38-47`
  - `app/api/pay/self-report/route.ts:21-56`
  - `lib/pay-grant.ts:44-45,57,64-81`
- **现象**：签名有效 ≠ 已付费。

## 影响
绕过付费、票据重放，资损。

## 关联修复方案
票据引入一次性 `jti` + 服务端已用表（或 `oid` 绑定订单）；`self` 申报改「待人工核对」状态；TTL 收窄 ≤5 分钟 + `jti` 防重放；CI 负向矩阵（无支付证明 / 重放 / 篡改 pid / 过期 / 跨商品 / 并发）。

## 验证关闭
- **验证方式**：CI 负向矩阵。
- **通过标准**：6 条负例全返 402/403 且无订单变更，正例恰放行一次、二次被拒。
- **状态**：**已关闭**
- **验证人 / 日期 / 结果**：专家团（自动化实测） · 2026-11-05 · 同套用例断言 free 票据在付费商品上 403、self 票据在真实通道存在时 403。
