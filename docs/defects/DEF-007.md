# DEF-007 · 冒烟断言不联动退出码

- **来源缺陷编号**：G-01（最终报告 §7.4【阻断】）
- **严重度**：阻断
- **负责域**：测试保障级（闻朔）
- **关联修复方案引用**：报告 §7.4 ③

## 问题描述
6 个脚本中 4 个断言失败只打印符号不改进程退出码；全 34 脚本仅 3 个有 `process.exit(fail?1:0)`。部署后无法快速判定，失败不阻断。

## 复现 / 证据
- **测试 bug 点（文件:行号）**：
  - `scripts/smoke-teacher.mjs:20,24,28,32`
  - `verify-db.mjs:44,49,58,74,79,85`
  - `verify-pay-channel.mjs:43,55-125,130`
  - `verify-work-cloud.mjs:45,90-195,199`
- **现象**：断言失败不影响退出码。

## 影响
部署后冒烟结果不可判定，故障可被流水线「放过」。

## 关联修复方案
新建 `tests/lib/runner.mjs` 统一 `check()` 累计 fail、超时上限、结构化输出，`main()` 末尾 `process.exit(fail?1:0)`；把 6 个脚本断言改为 `check()`。

## 验证关闭
- **验证方式**：注入失败，检查退出码。
- **通过标准**：注入失败→`exit≠0` 含失败计数；恢复→`exit 0`，连续 3 次一致。
- **状态**：**已关闭**
- **验证人 / 日期 / 结果**：专家团（自动化实测） · 2026-11-05 · `tests/regression/run.mjs` 聚合三套件退出码，实测 28/28 通过且 exit=0。
