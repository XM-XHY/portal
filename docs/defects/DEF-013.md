# DEF-013 · 失败静默降级（种子/默认→付费墙 fail-open）+ 单例不重连

- **来源缺陷编号**：RL-02（最终报告 §7.5【阻断】）
- **严重度**：阻断
- **负责域**：性能·可靠性（骆骋）
- **关联修复方案引用**：报告 §7.5 ③

## 问题描述
`lib/data/index.ts` 单例不重连、国产库连不上不回落；`supabase-repo.ts` 异常 / 空表静默返回 `defaultSite()` / `defaultContents()`；`payconfig.ts` 读失败返回 `defaultPayConfig()` → 经 `pay-access.ts` 构成付费墙 fail-open；调用方无法区分「库故障」与「库为空」。

## 复现 / 证据
- **测试 bug 点（文件:行号）**：
  - `lib/data/index.ts:7,22-26,52,64`
  - `lib/data/supabase-repo.ts:74-88,255-267`
  - `lib/payconfig.ts:29-43`（`defaultPayConfig()` 静默回落）
  - `lib/pay-access.ts:22-25`
- **现象**：库故障等价于付费墙消失。

## 影响
故障不可见、不可恢复，库故障 = 付费墙消失（与 SEC-01 同源）。

## 关联修复方案
付费门禁读失败改 fail-close（503 + 错误码 + 审计）；异常与空表返回可区分；为 `getRepo()` / `getWorkClient()` 增加健康重连或重启 SOP；`tests/chaos/` 注入断库 / 403 / 超时 / paycfg 损坏断言 5xx 而非免费。

## 验证关闭

- **通过标准**：断库 / 403 / 超时 / paycfg 损坏注入 ⇒ 5xx 而非免费。
- **本轮未实测；安全定性移交关屿。**
