# DEF-011 · 外部依赖无超时 / 重试 / 熔断，零故障注入验证

- **来源缺陷编号**：PF-02（最终报告 §7.5【阻断】）
- **严重度**：阻断
- **负责域**：性能·可靠性（骆骋）
- **关联修复方案引用**：报告 §7.5 ③

## 问题描述
支付网关与数据面 fetch 全无 `AbortSignal` / 超时 / 重试 / 熔断；`selfcheck` 自身可悬挂；已有 `lib/search.ts:62-74` 超时范式未覆盖支付与数据面。

## 复现 / 证据
- **测试 bug 点（文件:行号）**：
  - `lib/payment.ts:189-197,249-252,284-294,317-320,339-342,418-422`
  - `cloudbase-pg.ts:68-73`
  - `app/api/pay/selfcheck/route.ts:12`
- **现象**：外部依赖无边界控制。

## 影响
请求悬挂、半提交订单、依赖不可用时行为不确定。

## 关联修复方案
套 `fetchWithTimeout`（AbortSignal + 有界重试 + 熔断）；通道不可用明确降级（如 `/api/pay/order` 503 保留二维码路径且有用例）；`tests/chaos/` 注入 5xx / 连接拒绝 / 8s 超时断言无悬挂、无半提交订单。
