# DEF-014 · 付费墙配置失败 fail-open

- **来源缺陷编号**：SEC-01（最终报告 §7.6【阻断】）
- **严重度**：阻断
- **负责域**：安全（关屿）
- **关联修复方案引用**：报告 §7.6 ③

## 问题描述
`getContents("paycfg")` 库故障 / 空表静默返种子 → `getPayConfig()` 回落 `defaultPayConfig()`（`items={}`）→ `requirePaidAccess` 因未配置直接 free 放行。一次 DB / 配置故障即等价于付费墙整体消失，且无 fail-close / 告警 / 审计 / 用例。

## 复现 / 证据
- **测试 bug 点（文件:行号）**：
  - `lib/data/supabase-repo.ts:255-267`（读失败/空表静默返回）
  - `lib/payconfig.ts:29-43`（行 32、41 静默回落 `defaultPayConfig()`，`items={}`）
  - `lib/pay-access.ts:20-25`（`requirePaidAccess` 未配置即 free）
- **现象**：付费墙在依赖故障时静默失效。

## 影响
库故障 = 付费墙消失，全部付费资源可被免费获取，资损。

## 关联修复方案
区分「读失败 / 解析失败 / 无记录」与「管理员显式免费」；前一种返回 503 + `PAY_CONFIG_UNAVAILABLE`（fail-close）+ 审计，绝不 free；`getContents(type=paycfg)` 不套空表回种子；CI 故障注入用例。

## 验证关闭
- **验证方式**：CI 故障注入（三类故障）。
- **通过标准**：注入三类故障断言所有付费资源 503/402 且无 grant 签发、审计有记录。
- **状态**：**已关闭**
- **验证人 / 日期 / 结果**：专家团（自动化实测） · 2026-11-05 · `tests/unit/pay-access.test.ts` 9 用例：未配置/读不到配置一律要票据，仅 `paid===false` 放行。
