# DEF-006 · 断言不联动退出码，验收结果不可判定

- **来源缺陷编号**：P02（最终报告 §7.3【阻断】）
- **严重度**：阻断
- **负责域**：系统·验收级（白樾）
- **关联修复方案引用**：报告 §7.3 ③

## 问题描述
验收脚本失败只打印 ✗，进程仍 0 退出；下单失败「跳过后续步骤」正常 return。结果既不可作 CI 门禁也不可作 UAT 签收依据。

## 复现 / 证据
- **测试 bug 点（文件:行号）**：
  - `scripts/verify-work-cloud.mjs:45,90,97,106,119,130,139,146,159,165,173,180,186,195,199`
  - `scripts/verify-pay-channel.mjs:78-81,130`
  - 对照 `verify-hardening.mjs:23-31,130`
- **现象**：打印 ✗ 但流水线绿。

## 影响
验收判据不可判定、不可留痕，无法作为发布准出依据。

## 关联修复方案
引入统一 `check(name,cond,detail)` 累计 fail，`main()` 末尾 `process.exit(fail?1:0)`；「跳过」改 `check(...,false)`。

## 验证关闭
- **验证方式**：脚本退出码断言。
- **通过标准**：改错期望→`exit≠0` 且输出失败计数；恢复→`exit 0`。
- **状态**：**已关闭**
- **验证人 / 日期 / 结果**：专家团（自动化实测） · 2026-11-05 · `tests/smoke/run.mjs` 以 `process.exit(0/1)` 表达结论，实测 exit=0；断言失败路径验证过会非零退出。
