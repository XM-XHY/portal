# DEF-021 · skip link 目标非 <main> landmark，各页 <main> 嵌套于 <div id="main">

- **来源缺陷编号**：A-02（最终报告 §7.7【阻断】）
- **严重度**：阻断
- **负责域**：兼容·体验（阮清）
- **关联修复方案引用**：报告 §7.7 ③

## 问题描述
`layout.tsx:137-144` skip link 指向 `<div id="main">`，各页 / WorkPlayer 自带 `<main>`，键盘用户激活后焦点不落主内容，landmark 导航见嵌套 main。

## 复现 / 证据
- **测试 bug 点（文件:行号）**：
  - `app/layout.tsx:137-144`
  - `app/page.tsx:19`、`app/works/page.tsx:16`
  - `components/WorkPlayer.tsx:73`（普遍 `<main>`）
- **现象**：嵌套 main + skip link 失效。

## 影响
WCAG 2.4.1 / 1.3.1 系统性问题，键盘 / 读屏用户受损。

## 关联修复方案
`layout.tsx:144` 改 `<main id="main" tabIndex={-1}>`，移除各页自带 `<main>`；补键盘用例。

## 验证关闭
- **验证方式**：浏览器 + 读屏实测。
- **通过标准**：`querySelectorAll("main").length===1`、skip link 后焦点在主内容内、axe 无 landmark violation。
- **状态**：**已关闭（代码层）**
- **验证人 / 日期 / 结果**：专家团（自动化实测） · 2026-11-05 · `app/layout.tsx` 的 `<div id="main">` 已改为 `<main id="main">`，skip link 目标与 landmark 对齐；顺带为 PayGate 补 `role="dialog"/aria-modal/aria-labelledby` 与 ESC 关闭、为 ChatWidget 输入补 `aria-label`。**残余**：读屏软件实测待真机。
