## 问题描述
`lib/session.ts:6`、`lib/pay-grant.ts:28-34`、`lib/work-session.ts:16-22` 硬编码固定字符串常量作最后一级回落；仅 `session.ts:9-14` 有生产 warn，另两处无告警、无启动强校验。生产若未配 env，后台会话 / 付费票据 / 作品会话签名密钥为公开可猜值。另 `lib/data/hash.ts:13` 静态盐 `xx-tech-static-salt-v1` 兜底（生产已 fail-fast，见 `hash.ts:8-12`）。

## 复现 / 证据
- **测试 bug 点（文件:行号）**：
  - `lib/session.ts:6`（固定常量）、`lib/session.ts:9-14`（仅生产 warn）
  - `lib/pay-grant.ts:28-34`（固定兜底，无告警 / 强校验）
  - `lib/work-session.ts:16-22`（固定兜底，无告警 / 强校验）
  - `lib/data/hash.ts:13`（静态盐兜底；`:8-12` 生产已 fail-fast）
- **现象**：密钥来源可被预测 / 未强制。

## 影响

## 关联修复方案
