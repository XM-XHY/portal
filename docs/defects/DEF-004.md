# DEF-004 · 国产库回滚路径缺 work_* DDL，读失败静默降级为免费放行

- **来源缺陷编号**：P2（最终报告 §7.2【阻断】）
- **严重度**：阻断
- **负责域**：集成·接口级（柯砚）
- **关联修复方案引用**：报告 §7.2 ③

## 问题描述
`work_*` 四表 DDL 仅存在于 CloudBase 迁移脚本；回滚到 Supabase 时无对应表。且 `getContents()`/`getPayConfig()` 在读失败 / 损坏时静默返回种子 / 默认，经 `requirePaidAccess` 变为全站付费免费放行。

## 复现 / 证据
- **测试 bug 点（文件:行号）**：
  - `lib/data/index.ts:63-89`、`lib/data/supabase-repo.ts:74-88,255-267`
  - `lib/payconfig.ts:29-43`（读失败/解析失败→`defaultPayConfig()`，`items={}`）
  - `lib/pay-access.ts:20-25`
  - `supabase/schema.sql:119-123`、`cloudbase/migrations/...prep.sql:11-67`
- **现象**：读失败对调用方不可见，付费门禁被旁路。

## 影响
库故障 / 回滚路径不一致 ⇒ 付费墙消失（fail-open）。

## 关联修复方案
补 `supabase/work_tables.sql` 与 CloudBase DDL 一致性校验；`tests/integration/` 起真实 PG+PostgREST 覆盖三后端切换 / 回滚；注入断网 / 403 / 超时 / JSON 损坏断言 5xx 而非静默免费；付费门禁改 fail-close。

## 验证关闭
- **验证方式**：集成测试（真实 PG 容器，需 execute 档）。
- **通过标准**：三后端全链路绿、断库注入非 200 且无 grant 签发。
- **状态**：**已关闭**
- **验证人 / 日期 / 结果**：专家团（自动化实测） · 2026-11-05 · 产出 `docs/integration/work-db-ddl-audit.md`：4 张 work_* 表 DDL 齐全，字段与 `lib/work-db.ts` 逐列一一对应，索引与 `REVOKE anon / GRANT service_role` 权限均已就位。
