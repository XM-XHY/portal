# DEF-017 · claim 客户端自报 client 越权 + 恒真校验

- **来源缺陷编号**：SEC-04（最终报告 §7.6【阻断】）
- **严重度**：阻断
- **负责域**：安全（关屿）
- **关联修复方案引用**：报告 §7.6 ③

## 问题描述
`claim` 把「客户端自报 client 与订单快照相等」作独立放行条件（与 `sameUser` 为「或」），权益发给当前登录 uid；`:109` `ent.user_id!==uid` 首次恒真 → 另一账号凭 client 即可领他人已付订单会员；全程未校验 `o.productId===getWorkPlan(o.work.plan)?.payKey`、未排退款态。

## 复现 / 证据
- **测试 bug 点（文件:行号）**：
  - `app/api/works/pay/[action]/route.ts:90-120`
  - `lib/work-db.ts:202-239`
  - `lib/orders.ts:47-53`
- **现象**：越权领取他人已付权益。

## 影响
跨账号 / 跨产品领取会员，资损。

## 关联修复方案
收紧为仅 `sameUser`（服务端 `uid===o.work.userId`）放行，删 `sameDevice` 或改服务端设备凭证；增 `productId/payKey` 一致、`status=paid`、`!refunded` 三重校验；DB 唯一约束 + 条件写原子操作；6 条负例 + 并发 claim 入 CI。

## 验证关闭
- **验证方式**：CI 负向矩阵 + 并发 claim。
- **通过标准**：B 全部负例 403/400 且无 B 的 entitlement，A 权益恰 1 条、不叠加。
- **状态**：**已关闭**
- **验证人 / 日期 / 结果**：专家团（自动化实测） · 2026-11-05 · claim 收紧为必须 `o.work.userId === uid`；跨账号领取 403 由回归 P0-7 覆盖。
